# Kenira Inc. Website

Official website for **Kenira, Inc.** — video production & photography company.

- Video production, photography, drone cinematography, motion graphics, time-lapse, whiteboard animation, explainer & product videos, virtual tours, construction site monitoring, testimonial videos, and B-roll for indie filmmakers.
- Contact: Kenilramani@kenirainc.com · (267) 690-1880

## Deploy

This is a fully self-contained static site (`index.html` — all CSS/JS/assets inlined). Serve it from any static host:

- **Porkbun Static Hosting:** upload `index.html` to the site root.
- **GitHub Pages:** push to a repo and enable Pages (this repo is Pages-ready via `.nojekyll`).
- Any static host (Netlify, Vercel, Cloudflare Pages, S3): drop `index.html` in and go.
